# Uno Music App 📱

Official Android APK releases for **Uno Music App**, developed by **Uno (unoduxx75-a11y)**. This is a lightweight mobile music player application designed for seamless playback and clean audio performance.

## 🚀 Features
* Play offline audio files smoothly
* Clean, dark-themed user interface
* Light on system resources and battery storage

## 📥 Installation
Download the latest workable `.apk` file directly from the **Releases** section on the right side of this repository.
